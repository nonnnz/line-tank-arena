Technical choices

ProblemWhat we did
CheatingClients send only input (move direction, upgrade, cast). Server owns position, HP, XP, cooldowns and score.
Real-time syncWebSocket per player → Durable Object per room. 15 Hz snapshots, client interpolation ~100 ms, events pushed instantly.
IdentityLIFF ID token verified with LINE on the server, then our own HMAC session for the socket. Guests can play but are never ranked.
RankingsOnly the room server writes match results to D1. The same table feeds World Rank in-game and the OA /rank reply.
OA botWebhook signature checked, Reply API only (no push quota), short-lived channel tokens, works in group chats.
Service MessageAfter a match, the player taps “Send result to LINE”. The server sends their own recorded result through the MINI App Service Message API (notifier token → template), once per match.
CostWorkers, Durable Objects (SQLite), D1 and static assets — all on Cloudflare's free tier. Empty rooms stop ticking.
